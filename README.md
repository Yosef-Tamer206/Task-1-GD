# D2SR - Digital Forensics Landing Page

A landing page concept for a digital forensics service, with a drag-and-drop evidence upload area.

**Live demo:** https://yosef-tamer206.github.io/Task-1-GD/

![Task-1-GD screenshot](docs/screenshot.png)

## Features

- Dark and light theme toggle, saved between visits (`localStorage`)
- Mobile navigation menu
- Drag-and-drop file upload area with file preview (name and size)
- "Analyze" interaction that confirms the selected file
- Sections for about and how-to-use
- Responsive layout

## Tech Stack

- HTML5, CSS3, vanilla JavaScript
- Font Awesome icons
- Inter font (Google Fonts)

## Run Locally

```bash
git clone https://github.com/Yosef-Tamer206/Task-1-GD.git
cd Task-1-GD
```

Open `index.html` in a browser.

## Notes

- The upload and analyze flow is a front-end demo only. No file leaves the browser and there is no real forensic analysis behind it.
